Four harnesses.
One update run.

update-all is an agent skill. Say /update-all and your agent updates Codex, Claude Code, pi, and Antigravity CLI, then prints one before/after version table with every failure shown exactly.

git clone https://github.com/cskwork/update-all-skill ~/.agents/skills/update-all

  • Read the skill instructions
  • View the repository

The ledger

One updater per harness. Only harnesses found on PATH are touched.

  1. Codex codex update Version read with codex --version.
  2. Claude Code claude update Version read with claude --version.
  3. pi pi update Runs pi update --all only when you explicitly ask to include extensions or packages.
  4. Antigravity CLI agy update Version read with agy --version.

Three steps, every run

  1. 01

    Snapshot

    command -v checks each binary. Installed harnesses report <cli> --version. Missing ones are marked not installed and skipped. A failed version read is recorded with its exit code and stderr, never guessed.

  2. 02

    Update

    Each installed harness runs its own updater. One failure never stops the others, and the exact exit code and stderr are kept. Nothing is installed, no sudo, no fallback installers.

  3. 03

    Verify & Report

    --version runs again for every originally installed harness, even after a failed update. One table comes back, with exact stderr for each failure below it.

What comes back

Illustrative example. These are not current or latest versions.

updated / unchanged
The updater exited 0 and both version reads succeeded. Only then are versions compared.
failed (exit N)
The updater exited nonzero, or a version read failed. An updater failure stays failed even if the after version differs.
not installed
The binary was not found. Nothing runs, and the skill never installs it for you.

Install and run

Clone into your skills directory

git clone https://github.com/cskwork/update-all-skill ~/.agents/skills/update-all

Needs an agent host that loads skills from ~/.agents/skills, plus at least one supported harness on PATH.

Invoke it

/update-all

To include pi extensions and packages, ask for it explicitly, for example /update-all including pi extensions. Then pi update --all runs instead of pi update.

Optional: Hermes

mkdir -p ~/.hermes/skills
ln -s ~/.agents/skills/update-all ~/.hermes/skills/update-all

The destination ~/.hermes/skills/update-all must not exist before you link it.
